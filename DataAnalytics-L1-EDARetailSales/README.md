# Retail Sales Data Analysis

## Project Overview

This project explores retail sales data to understand sales performance, customer purchasing patterns, and product category performance.

## Objectives

- Examine and clean the dataset.
- Calculate summary statistics for numerical columns.
- Analyse monthly and quarterly sales trends.
- Explore customer demographics and product categories.
- Identify important findings and make data-driven recommendations.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project File

- retail_sales.ipynb — contains the analysis, visualisations, findings, and recommendations.
 

## Key Findings

The analysis compares sales performance over time, examines revenue across product categories, and explores differences in purchasing patterns across customer groups.
